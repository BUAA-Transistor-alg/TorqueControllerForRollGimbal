# Task-2 工作总结：状态空间平滑与 MAP 估计

## 任务目标

实现基于最大后验估计的参数辨识，将干净轨迹、初始状态、力矩噪声作为隐变量，使用正确的噪声模型进行估计。

## 实现方法

### 1. 参数类切换（关键突破）

根据 Lead 指示，从旧的 33 维参数类切换到新的 28 维可辨识参数类：
- 使用 param_basis.py 提供的经验可辨识基（24 惯性 + 4 阻尼）
- 可辨识维数从文档的 21 增加到 24（地形倾角带来额外信息）
- 旧参数类存在 7.90e-2 N·m 量级的不可约模型误差

### 2. 两阶段优化框架

**外层**（分段数据）：
- 将长数据切分为多个短窗口（100-200 步）
- 每窗独立优化初始状态 (q0, v0)
- 使用 Nelder-Mead 最小化仿真与观测的加权残差

**内层**（参数估计）：
- 固定初始状态和偏置（标称几何）
- 对 44 维惯性参数做加权线性最小二乘
- 投影到 28 维可辨识子空间
- 正则化项拉向先验（ridge regression）

**噪声模型加权**：
- 位置通道：WEIGHT_Q = 1.0 / (0.001^2)
- 速度通道：WEIGHT_V = 0.01 / (0.1^2)（降低权重）

### 3. 物理约束处理

使用 param_basis.physical_model 投影到物理可行域：
- 质量 > 0（softplus 参数化）
- 惯量正定（Cholesky 分解）
- 在可辨识子空间保持一致的前提下满足物理约束

## 遇到的问题

1. **物理边界问题**：线性回归可能将参数推向物理边界（B4 惯量最小特征值 1e-6），导致 Cholesky 分解失败

2. **计算成本**：状态空间平滑需要大量 forward_step 调用（每段每次迭代数百次），在大规模数据上效率较低

3. **优化收敛**：初始状态优化在某些段上收敛缓慢，可能需要更好的初值或约束

## 经验教训

1. **线性回归优先**：当问题对参数线性时，直接利用线性性比状态空间平滑更高效

2. **物理边界敏感**：接近物理边界的参数需要谨慎处理，投影可能不稳定

3. **初值重要**：好的初值（如 regressor EIV 结果）比复杂的优化算法更关键

4. **计算成本权衡**：在有限计算资源下，简单有效的方法优于复杂但昂贵的方法
