# 完整惯性参数回归复核

运行命令：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 regressor_fit.py --evaluate
```

脚本读取含噪位置与含噪力矩，通过位置平滑求一阶和二阶导数。SG、Gaussian 加权局部多项式和三次平滑样条均可配置。二阶导数滤波矩阵乘以零阶保持的双重积分矩阵，形成力矩滤波核，保证离散时间匹配。

固定偏置时使用 C 库的 44 列空间惯量回归矩阵。该矩阵的结构秩为 28，其中惯性部分为 24，阻尼部分为 4。8 个偏置另外保存，因此 reduced 键为 36 维；其前 28 项是保存的 basis 矩阵对应的正交可辨识坐标，最后 8 项依次为 o2.x、o2.y、o3.x、o3.y、o3.z、o4.x、o4.y、o4.z。model 键为 56 维物理模型。

加权 LS 用每个样本的加速度噪声增益乘以质量矩阵，计算力矩方差。TLS 使用列归一化后的增广矩阵 SVD。解析 EIV 修正对 q、qdot、qdd 的回归量导数进行中心差分，累计完整导数交叉协方差，并从 ATA 中扣除相应项。质量、一阶矩与原点惯量组成的六阶空间惯量矩阵施加正定约束，阻尼施加非负约束。

超参数选择使用前 80 段拟合、后 20 段含噪轨迹验证，干净字段与真实参数只进入 eval_openloop 的报告。选定 SG51/5 与 corrected 方法后用全部 100 段重新拟合；此时 JSON 的 validation 数值是包含训练段的诊断值。

完整扫描包括 SG 的 21、31、41、51 点以及三阶、五阶；局部多项式的 21、31、41 点；三次平滑样条的 1e-4、1e-3 平滑系数；WLS、TLS、解析 EIV 三种回归方法。扫描指标分别保存在 data/regressor_fullscan_metrics.json 与每个模型的相邻 JSON 文件。

100 段 corrected SG51/5 的实测：50 步 RMSE 为 0.000225048、0.000950152、0.000361926、0.000305037；MAX 为 0.00128904、0.00653818、0.00237131、0.00250340；direction_wrong 为 0。两种静止力矩的加速度方向一致比例均为 1.0。roll 最大误差仍超过规范的 0.005。

模型先验位置重建已经运行验证：拟合损失降低到 0.4209，但 50 步 RMSE 恶化到 0.00329、0.00949、0.00187、0.00190，direction_wrong 增加到 15。该方法保留为显式 --refine 选项，默认配置不使用它。偏置 L-BFGS-B 外层由 --outer 控制，采用 1e-4 m 数值差分步长和标称几何附近的边界。已运行两次外层迭代：WLS SG51/5 的 50 步 RMSE 为 0.000678、0.001894、0.000472、0.000565，方向错误 1 次，含噪验证评分未优于默认配置。

另以共同验证初始状态及消去初始状态误差的 50 步含噪轨迹剖面评分进行复核，保存共同验证和剖面验证 JSON。剖面评分选择 SG41/5 后用全部数据重拟合，实测 roll RMSE 为 0.001134、方向错误 1 次。该补充实验未替换已保存的 SG51/5 默认交付。所有候选均保留独立模型及相邻指标文件。
