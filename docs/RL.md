# 强化学习自适应控制器

分支 `sac-adaptive`。目标是训练一个循环控制器，使四个关节角跟踪带阶跃、漂移与超限目标的参考曲线，
在动力学参数与电机力矩系数每回合随机变化、且回合内缓慢漂移时，保持与参数已知或固定参数训练相当
的控制精度，贴近关节限位但不撞限位，并且控制器内部的循环状态能够在线估计当前的等效扰动。

## 1 环境

被控对象是仓库 C 库 `gimbal_dynamics` 的四自由度串链云台（B0 棋盘固定 → B1 大 yaw 绕 z →
B2 roll 绕 y → B3 小 yaw 绕 z → B4 pitch 绕 x）。环境代码在 `python/rl/tracking_env.py`。

### 1.1 参数采样与电机系数

每个回合重置时采样一组动力学参数：质量与阻尼按 `exp(U(-s, s))` 缩放，每个刚体的惯量按同一个标量
缩放 `exp(U(-min(s,1.2), min(s,1.2)))`（保证张量正定），质心偏移 `U(-0.03, 0.03)·min(s,1)` 米，
安装偏置 `N(0, 0.03·min(s,1))` 弧度；采样后用逆动力学与随机力矩开环仿真检查可行性。

每个关节的电机力矩系数按该参数下的能力采样：
`scale_j = min(8, max(1.5·最大重力力矩_j, 20·关节空间惯量对角_j) + U(0.5, 1.5))` 牛米。
重力力矩在水平、10° 坡度与限位角点共 48 个姿态上取最大，惯量对角取零位值；任一项下限超过 8 牛米
的候选直接重采，保证采样到的模型在限位内任意姿态都能被力矩撑住。动作 `a ∈ [-1, 1]` 映射为力矩
`τ_j = a_j · scale_j`。

**回合内漂移**：`drift_scale` 与 `drift_motor` 大于零时，重置时另采一个参数终点（质量、每个刚体
惯量、阻尼按保持符号的几何插值，电机系数按同比例漂移，终点同样校核力矩能力），回合内按回合进度
从起点缓慢变到终点，每 10 步重建模型与可辨识坐标。训练第二阶段取 `drift_scale = 0.35`、
`drift_motor = 0.3`，即约 42% 的参数变化与 35% 的电机系数变化分布在 15 s 内。

### 1.2 参考轨迹

每个关节两个正弦分量（频率 0.2 到 1.2 rad/s）、0 到 3 个随机阶跃（幅度 ±0.35 rad 内随机）、
大 yaw 以 0.6 的概率带 0.1 到 0.4 rad/s 的持续漂移。有限位的关节参考被夹在限位外 0.35 rad 以内，
因此阶跃与连续变化都可能把目标推到限位之外。回合初始状态放在软限位（硬限位内侧 0.07 rad）以内，
避免从硬挡块上起步把初始化误差算成碰撞。

### 1.3 观测（142 维）

| 索引 | 维度 | 内容 |
|---|---|---|
| 0–7 | 8 | sin/cos 关节角（带噪声与偏差） |
| 8–11 | 4 | 关节角速度 |
| 12–19 | 8 | sin/cos 参考角 |
| 20–23 | 4 | wrap 跟踪误差 |
| 24–27 | 4 | 参考角速度 |
| 28–107 | 80 | 未来 20 步（0.2 s）目标预瞄，相对当前参考，带随时间增长的偏移与噪声 |
| 108–111 | 4 | 上一步动作 |
| 112–115 | 4 | 一阶低通后的角加速度 |
| 116–121 | 6 | sin/cos 坡度与坡向、sin/cos 底盘偏航 |
| 122 | 1 | 底盘偏航角速度 |
| 123–125 | 3 | 底盘线加速度 |
| 126–129 | 4 | 标称模型前馈需求（放大 5 倍） |
| 130–133 | 4 | 标称模型偏置力矩（放大 5 倍） |
| 134–137 | 4 | 动作失配 |
| 138–141 | 4 | 动作失配的滑动平均（负载估计） |

标称特征用**设计参数**（`params.py`）而不是被控对象的随机参数计算：把当前参考按 0.07 rad 软裕度
裁剪，用预瞄做二次拟合得到前馈加速度，叠加比例反馈与限位制动得到期望角加速度，再用标称模型的
逆动力学换算成"本应施加的动作"。动作失配是"指令动作的低通"减去"用标称模型对测得角加速度反演出的
动作"，负载是失配的一阶滑动平均（速率 0.1）。全部观测量都带噪声与偏差：角度 0.003 rad + ±0.010
偏差，角速度 0.05 + ±0.020 + 3% 比例，坡度 0.5° + ±1°，坡向 2° + ±5°，底盘偏航 2° + ±5°，
偏航角速度 0.05 + 0.1，底盘加速度 0.02 + 0.05。

### 1.4 奖励

每一步的代价为

```
位置：mean_j [ r²/(1 + r²/9) + 1.5·|e_j| ]，r = e_j / 0.02
速度：0.05 · mean_j [ v²/(1 + v²/25) ]，v = (dq_j - dq_ref_j) / 0.5
力矩：0.02 · mean_j (a_j²/4)
平滑：0.02 · mean_j ((a_j - a_j^prev)²/4)
限位裕度：30 · mean_{受限关节} [ clamp((0.0349 - d_pred)/0.0349, 0, 1)² ]
         d_pred = 离最近限位的距离 - 向内速度 · 0.04 s
撞限位：100 · hit，超出限位幅度平方：1000 · overshoot²
```

奖励为 `-0.05 · 代价`，固定尺度，不做运行标准化与截断。限位裕度项用 0.04 s 的速度预判，
让高速接近限位时惩罚提前出现。

## 2 结构化自适应控制器

`python/rl/teacher.py` 的 `StructuredTeacher` 是一个只用观测即可实现的自适应控制律：

```
a = clip(Σ_k w_{jk} · [前馈需求_j, 偏置_j, 负载_j, 1], -1, 1)
```

其中前馈需求、偏置与负载都来自观测的第 126–141 维，权重 `w` 由
`python/rl/calibrate_structured.py` 用**真参数教师**的动作做岭回归标定，当前值（大 yaw、roll、
小 yaw、pitch，四列依次为前馈需求、偏置、负载、常数）：

```
[[0.9753, 1.3625, 0.2348, -0.0187],
 [1.0112, 0.8489, 0.7720,  0.0383],
 [1.0303, 0.7832, 0.7191, -0.0284],
 [1.2029, 1.0908, 0.9858, -0.0182]]
```

真参数教师 `TeacherController` 知道真实动力学参数与电机系数：由预瞄拟合期望加速度，叠加比例反馈
（Kp 196、Kd 28）与限位制动（制动减速度 14 rad/s²、软裕度 0.07 rad），用真实模型的逆动力学与盒约束
下的有界力矩分配得到动作。它代表参数知识的性能上限。

## 3 循环残差 SAC

`python/rl/networks.py` 与 `python/rl/sac.py`。控制器 = 结构化前馈 + 循环残差：

```
a = clip(a_struct + 0.25 · tanh(μ(h_t) + σ·ε), -1, 1)
```

- 隐藏状态 `h_t = [h_fast, h_slow]`：快路 64 维门控线性递归（`h = a_t ⊙ h_{t-1} + (1-a_t) ⊙ W x_t`，
  gate 偏置 2）吃前 134 维观测；慢路 64 维 GRU 只吃动作失配与负载两段（8 维）。
- 慢路按**一阶滑动平均解析初始化**：更新门偏置取 `logit(0.9)`，候选状态前 4 维等于输入前 4 维，
  其余输入与循环权重为零；负载头（线性）初值取恒等读出。因此回合开始时慢路状态就是动作失配的
  滑动平均，控制器从一开始等价于标定好的结构化自适应控制器；训练中慢路与负载头冻结，作为控制器
  固定的在线扰动估计器，避免价值梯度破坏前馈补偿所依赖的估计。
- 残差头为两个 256 隐层，输出 4 维残差均值；探索标准差固定为 `exp(-2)`（残差是在已工作控制器上的
  小修正，不需要大的探索噪声，也避免价值梯度把噪声推大）。
- 两个动作价值网络各带同样的快慢两路编码器（两层 256 隐层），序列回放窗口 32 步、批次 16、
  每迭代 32 次更新、回放容量 140 回合、软更新 0.005、折扣 0.99；学习率：残差头 1e-4、
  价值网络 3e-4、辅助头 3e-4。
- 辅助监督头把动力学信息压进状态，同时作为可读性探针：参数回归（慢路 → 28 维规范固定可辨识坐标
  + 4 维相对电机增益）、响应回归（慢路 + 真实状态 → 当前等效扰动与有效惯量，动作单位）、
  动力学预测（慢路 + 动作 + 真实状态 → 下一拍真实角加速度）、负载回归（慢路原始状态 → 动作失配
  滑动平均，权重 1.0）。

### 3.1 训练流程

单个训练回合 1500 步（15 s）、8 个并行环境。前 10 到 30 次迭代只训练价值网络与辅助头（预热），
之后联合更新残差头。参数尺度按 `U(0, s_max)` 每回合采样，`s_max` 在前 35% 迭代从 0.8 线性升到 1.75；
漂移幅度从 25% 迭代开始线性升到 `drift_scale = 0.35, drift_motor = 0.3`。每 10 到 20 次迭代在固定
种子上评估并保存"选择分"最低的检查点（选择分 = 各评估尺度的限位内误差 + 0.02 × 单回合最大撞限位数）。
训练分两段：

1. **强化学习段**：按上段配置用 SAC 训练残差头，得到 `data/rl_adaptive_best.pt`。
2. **蒸馏段**：用真参数教师的动作对残差做监督蒸馏（`--supervised --true-teacher`，行为克隆权重
   1.0，其余辅助权重降到 0.05，参数尺度 1.2 到 1.75、漂移 0.35/0.3），在同样的评估协议下继续
   45 次迭代，取选择分最低的检查点作为最终策略（`data/rl_distill_best.pt`，另存 `data/rl_final.pt`）。
   真参数教师的动作与结构化前馈只差 0.03 量级的均方根，蒸馏在这里只是一次小幅度校正：同一 4 回合
   评估协议下把参数尺度 1.75 的限位内误差从 0.0189 降到 0.0181，全量 8 回合协议下最终为 0.0168。

训练曲线里的撞限位次数包含带探索噪声与高尺度漂移的训练回合，不代表部署时的确定性行为；
部署行为见第 4 节的固定种子评估。

## 4 结果

控制评估用种子 7000 到 7007（8 个回合，每回合 1500 步），参考控制器用同一批种子；状态评估用
种子 21000 起（12 个回合）。"限位内误差"指只统计参考在硬限位以内的采样点、
四个关节跟踪误差绝对值的平均。

| 0.0 | **0.0151** | 0.0172 | 0.0132 | 0.0170 |
| 0.5 | **0.0123** | 0.0144 | 0.0085 | 0.0146 |
| 1.0 | **0.0163** | 0.0205 | 0.0099 | 0.0207 |

| 2.0 | **0.0189** | 0.0216 | — | — |
| 2.5 | **0.0240** | 0.0250 | 0.0133 | 0.0251 |

"固定参数专训基线"使用完全相同的网络与训练流程，但参数尺度固定为 0、不引入漂移、只训练残差头。
本策略在每一档都优于这条基线：固定参数档误差是基线的 0.88 倍，与真参数教师的差距就是参数知识的
代价（0.0151 对 0.0132，约 14%）。参数尺度从 0 加到 2.5 时限位内误差从 0.0151 增到 0.0240（1.59 倍），
结构化控制器是 0.0170 到 0.0251（1.48 倍），真参数教师是 0.0132 到 0.0133。
真参数教师的软件限位裕度是 0.035 rad（比结构化控制器小一半），所以它在参数尺度 0 的评估里会出现
碰撞；这一列只用于比较跟踪精度，不用于比较限位行为。

分关节（尺度 1.0，限位内）：大 yaw 0.0065、roll 0.0197、小 yaw 0.0257、pitch 0.0136 rad；
固定参数专训基线为 0.0072 / 0.0349 / 0.0366 / 0.0132。阶跃响应峰值误差 0.18 到 0.25 rad。

尺度 1.0，参数与电机系数漂移幅度 0.35 / 0.3；配对的"冻结漂移"对照使用同一批随机种子、同一段参考

|---:|---:|---:|---:|---:|

给出几乎相同的误差，因为负载滤波的有效滞后约 10 步（0.1 s），远快于 15 s 的漂移。

### 4.4 噪声与偏差放大

参数尺度 1.5、观测噪声放大 4 倍时限位内误差 0.0178，观测系统偏差放大 3 倍时 0.0201，
两组都零碰撞（基准为 1.0 与 1.0 倍）。

### 4.5 隐藏状态

| 指标 | 恒定参数 | 回合内漂移 0.35 |
|---|---:|---:|
| 负载回归 R²（慢路状态 → 动作失配滑动平均） | 0.9999 | 0.9997 |
| 漂移下负载回归五个时段的 R² | — | 0.9998 / 0.9998 / 0.9997 / 0.9997 / 0.9997 |
| 漂移下负载预测变化方向与真实变化方向的余弦 | — | 0.9991 |
| 慢路状态每步清零后跟踪误差 / 完整状态 | 3.41 倍（0.0277 → 0.0944） | — |
| 冻结慢路状态 / 完整状态 | 1.58 倍 | — |
| 单次交换慢路状态 / 完整状态 | 1.01 倍 | — |
| 持续交换 100 步 / 完整状态 | 1.27 倍 | — |
| 线性探针（慢路状态 → 32 维参数标签）R² | 0.19 | — |

慢路状态在线估计的就是"当前等效扰动"：它由动作失配（指令动作与按标称模型反演出的动作之差）积分
得到。每步清零后控制器立刻失去前馈补偿，跟踪误差退化到没有负载补偿时的水平（0.0944 rad，与标定
阶段测到的负载置零误差 0.060 到 0.065 同量级）。单次交换影响很小，因为负载是一阶滑动平均，注入
一次后 10 步内就回到自己的轨迹；持续交换 100 步才明显退化。漂移条件下负载回归在五个时段都保持
0.9997 以上，负载预测的变化方向与真实参数引起的变化方向余弦 0.9991，说明状态跟踪的是参数变化而
不是参考动作造成的伪变化。

慢路状态对 32 维参数标签的线性可读性只有 0.19，与辨识研究的结论一致：闭环控制轨迹里参数信息主要
体现为控制相关的组合（相对增益、动作单位的扰动与有效惯量），完整的 28 维坐标在整体尺度不可观测、
闭环激励不足的条件下无法高精度恢复。`PARAMETER_IDENTIFIABILITY.md` 与两轮独立研究都复现了这一点。

## 5 讨论与局限

1. **结构化前馈是必要的**。从零模仿真参数教师的高增益控制律对动作精度要求极高：动作均方根误差
   0.15 就足以让闭环发散（实测跟踪误差 0.30 rad、大量碰撞）。先标定"标称模型前馈 + 比例反馈 +
   限位制动 + 负载补偿"的结构化控制律、再学习残差，可以在训练一开始就得到教师级别的跟踪与限位
   行为，强化学习只需要做小修正；在有对照的五个尺度（0、0.5、1、1.75、2.5）上最终策略的限位内
   误差都低于结构化控制器本身。
2. **整体尺度不可观测**。质量、惯量、阻尼与电机系数同时乘同一个正数会得到逐位相同的仿真轨迹
   （角差 1e-16 量级），因此绝对参数坐标不是可学习的对象。控制器需要的量与评估采用的物理目标
   都必须是尺度归一的（相对电机增益、动作单位的扰动与惯量、固定姿态保持力矩）。
3. **闭环参数辨识的上限**。独立研究实测：已知真实电机系数时，固定名义基的 28 维投影可以到 R²
   0.88 到 0.99；一旦用带噪测量与未知电机系数，投影 R² 变为负值。本策略因此把状态监督目标放在
   "当前等效扰动"上，它在恒定与漂移两种条件下的回归 R² 都在 0.999 量级。
4. **高参数尺度的残余碰撞**。尺度 2.5 的 8 个评估回合里仍有 1 个回合出现 6 个碰撞步，集中在 roll
   上：该轴行程只有 50°、上界 5°，参数极端时执行器力矩接近饱和，负载估计的残差把关节缓慢推向
   挡块。尺度 0 到 2.0 的全部 40 个评估回合里没有碰撞。
5. **训练成本**。单次训练在 18 核 CPU 上约 20 到 40 秒一次迭代（8 环境、1500 步回合、32 次更新），
   完整流程（结构化标定、预热、强化学习、最佳检查点筛选）约 1 到 2 小时。

## 7 部署与可视化

`python/rl/deploy.py` 提供 `PolicyController`，把训练好的策略接到任意 `gimbal_dynamics` 状态上：

- 每 10 ms 更新一次（与训练的控制周期一致）。内部维护最近 0.2 s 的目标位置缓冲（21 个采样），
  用缓冲的斜率外推未来 0.2 s 的预瞄参考，作为观测里的预瞄段与参考角速度。
- 观测按训练时的 142 维布局组装：角度与角速度取精确状态，坡度、坡向、底盘偏航与加速度取自
  传入的 `terrain` 与 `base`；标称特征、动作失配与负载沿用 `tracking_env` 的实现。
- 输出为归一化动作乘标称电机力矩系数（`nominal_model` 给出的尺度，与标称特征同一把尺子）。

界面与仿真后端、控制器的分工：

- `python/visualization/backend.py`：仿真后端，接口与 `gimbal_env.Environment` 相同
  （reset / step / close，返回包含关节角、角速度、坡度、坡向、底盘状态的观测字典），默认实现是
  100 Hz（dt = 0.01 s）的 `GimbalEnv`。换成真实世界控制时实现同一个接口并在创建 `Viewer`
  时传入即可。
- `python/visualization/controllers.py`：三种控制器（直接力矩、PID 目标位置、策略网络目标位置），
  只读取观测字典、按键输入与时间步，输出四维力矩。PID 控制器自带偏置力矩前馈；策略控制器复用
  `python/rl/deploy.py`。
- `python/visualization/ui.py` 只负责 PyBullet 显示、键盘输入与 100 Hz 主循环，所有模式共用同一个
  仿真节拍，单步 0.01 s。

界面上的策略模式：

- 按 `m` 在 直接力矩 / PID 目标位置 / 策略网络目标位置 三种模式间循环切换，`--mode rl` 可直接启动。
- 目标位置的产生方式与 PID 模式相同：按住 `1` 到 `8` 以 `--target-rate`
  （默认 `params.PID_TARGET_RATE`，3 rad/s）移动对应关节的目标；进入模式时目标取当前关节角。
- 策略模式的目标位置范围与控制器一致：大 yaw 不限幅，其余三轴取硬限位内侧 0.07 rad
  （roll 从 −0.7154 到 0.0173、小 yaw ±0.8027、pitch ±0.7154 rad），预瞄外推同样按这个范围裁剪；
  PID 模式仍然限制在 ±π。
- 无界面自检（100 Hz，每步 0.01 s）：
  - 不按键：100 步后角度 `[0.0037, 0.0167, −0.0039, 0.0081]` rad，速度在 1e-4 量级。
  - `--steps 200 --torque 1`（按住大 yaw）：目标 6.0 rad，角度 6.034 rad，速度 3.0 rad/s。
  - 按住 roll 正方向：目标停在 0.0173 rad，角度 0.0277 rad，没有越过 0.087 rad 的硬限位。
  - 直接力矩模式按住大 yaw 3 s：角度 30.4 rad、角速度 18.9 rad/s，数值有限（仿真后端不设挡块，
    开环力矩持续加速，转速由阻尼决定）。
  - PID 模式下把 roll 目标指令到 π：关节跟随到 3.159 rad（仿真后端不设挡块），角速度 0.034 rad/s。
